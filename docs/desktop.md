# mycode-desktop

唯一的产品前端，GPUI。这个 crate 负责画，以及把点击变成 `DesktopAction`。会话、提供商、工具、路径和密钥的读写都在 `mycode-app`。

```text
GPUI 元素
    │ 点击、输入
    ▼
DesktopAction → reduce（纯函数，无 IO）
    │ 需要核心时
    ▼
BridgeCommand → CoreBridge
    │ BridgeEvent / BridgeReply
    ▼
再 reduce 一次，元素按新状态重画
```

视图模型和 GPUI 分开，是为了产品行为不依赖一块 GPU。CI 不打开窗口；它编译桌面 crate 并跑 `clippy`。

## 模块

| 模块 | 干什么 |
| --- | --- |
| `main` | 解析家目录，打开窗口。发布构建在 Windows 上不分配控制台 |
| `workspace` | 窗口实体：桥、轮询、标题栏、侧栏、对话、检查器、设置页 |
| `workspace/bridge` | 把动作译成命令，把事件译成动作 |
| `workspace/projects` | 工作区、文件夹、会话的创建、切换和删除 |
| `workspace/settings_editor` | 设置表单的保存。密钥框在保存后丢掉，不把已存的钥匙填回来 |
| `workspace/updates_data` | 更新对话框和导入导出 |
| `view_model` | `WorkspaceState` 和 `reduce`。子模块按对话、项目、模型、设置、用量拆开 |
| `ui` | 按状态出元素。窄窗口留下侧栏、收起右侧检查器 |
| `ui/sidebar` | 工作区切换器、文件夹、该工作区的会话 |
| `ui/chat` | 欢迎页、转录、作曲栏、`@` 与模型菜单、提问卡 |
| `ui/context` | 当前模型、用量、git 改动。文件列表先给前几个，其余进全高抽屉 |
| `ui/settings` | General、Models、Agents、Skills、MCP、Web、Data、About |
| `git_status` | 只读 `git status`。快照不变就拉长间隔 |
| `i18n` | `auto` 跟系统语言，否则用设置里的 `en` / `zh` |

视觉是 Desk：毛玻璃、发丝边、暖色强调。主题和调色板来自 `ui.json` / 设置，不在渲染层写死业务状态。

## 窗口里有什么

- **侧栏。** 头部是工作区切换器，可以新建、重命名、删除。一个工作区挂多个文件夹；会话显式属于一个工作区。当前文件夹是相对路径的工作目录，其它文件夹用绝对路径。首次升级会把原来的文件夹列表收成一个工作区，名字随界面语言，中文是「默认」。
- **对话。** 作曲栏旁边换模型和思考强度。子代理不在转录里重复刷进度；底部状态行和右侧卡片各有一处，结束后卡片消失。卡片可以取消该子代理。
- **检查器。** 这个会话正在用的模型，以及当前文件夹的 git 改动。点文件看 diff。
- **欢迎页。** 打开文件夹或直接开始。最近项目可以删。
- **设置。** 密钥输入框在已保存时显示锁。点锁是换一把新的，旧钥匙不会被填回输入框。MCP 的添加在二级页：目录、导入 JSON、自定义。

提示是右下角短暂气泡。更新在右上角：可更新、下载中、待安装。下载校验完成后弹出对话框，确认才重启安装。失败原因收成一行，不把整段 HTTP 错误铺开。

窗口开在主屏可用区域正中。屏幕比默认的 1520×960 小，就先缩小再居中，最小约 960×560。

## 视图模型

`reduce` 是唯一改 `WorkspaceState` 的地方。模型选择、设置的 revision、更新状态机、排队的未发送消息（有条数上限）、转录分页，都是动作。渲染层可以克隆它需要的切片，不能自己改会话归属或用量合计。

流式回复有字符上限。用量在回放（只有模型名）和实时（provider/model）之间按同一把钥匙合并，缓存占比在重建后还在。检查器选中的模型对不上任何行时，显示实际跑过的模型。

坏会话在侧栏占一行，只能删，不能打开。

## 和核心的节拍

事件轮询间隔 50ms。git 快照在变化时约每 2 秒一次（40 个 tick），连续不变则退到 4 秒、8 秒；一切文件夹或快照变化就回到 2 秒。自动检查更新在进程活过大约一天后再跑一次。

`SendMessage` 和 `RecallMessage` 带上界面看到的账本头。核心拒绝过期头时，界面保持原对话并提示，不本地假装已经撤回。

## 不放在这里的东西

不拼 HTTP，不解析会话日志，不保存密钥。设置页提交的是完整 `AppSettings` 加上读到的 revision；钥匙单独走 `SaveProviderKey`。
