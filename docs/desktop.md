# mycode-desktop

桌面图形前端，GPUI。这个 crate 只负责窗口、绘制和输入；状态与产品决定都在 `mycode-frontend` 的 `FrontendDriver`（`WorkspaceState` + `reduce`）。终端前端 `mycode-cli` 用同一个驱动。会话、提供商、工具、路径和密钥的读写都在 `mycode-app`。

```text
GPUI 元素
    │ 点击、输入
    ▼
FrontendAction → FrontendDriver → reduce（纯函数，无 IO）
    │ 需要核心时
    ▼
BridgeCommand → CoreBridge
    │ BridgeEvent / BridgeReply
    ▼
再 reduce 一次，元素按新状态重画
```

视图模型与 GPUI 分开，产品行为不依赖 GPU。CI 不打开窗口。PR 只在 `windows-latest` 上跑整个 workspace 的 `cargo test --workspace --locked` 和 `cargo clippy --workspace --all-targets --locked -- -D warnings`（dev/test profile），不构建发布版。推 main 时，同一检查加三个原生构建：Windows x64、Windows ARM64、macOS Apple Silicon。发布构建用 `[profile.release]`（fat LTO、单 codegen unit）和 `RUSTFLAGS=-Dwarnings`，不跑测试。没有 Linux 包，也没有 fmt 任务。

发布资产按可执行文件名分前缀：`mycode-desktop` 与 `mycode-cli` 各出一份 zip，均带 `.sha256`；macOS 另用 `scripts/make_dmg.sh` 把桌面版装进 `MYCode.app` 并生成 dmg（ad-hoc 签名），zip 保留给自更新。`release-plan` 在 tag 已占用时于临时提交上 bump patch；Windows 检查和三个构建都成功且计划要求发布时，才打 tag、发布 GitHub Release 并快进 main。

## 模块

| 模块 | 干什么 |
| --- | --- |
| `main` | 先处理 `--mycode-apply-update`，以及 `--help` / `--version` / 未知参数；然后由 `mycode_frontend::cli::launch`（CLI 共用）清理过期的更新暂存目录、解析家目录、重放上次未完成的更新（`Armed` 直接退出换新版本，`Applied` 只报告一次），再由 `ensure_desktop_installed` 把下载的二进制搬进安装目录（需要时重启自身），最后打开窗口。发布构建在 Windows 上不分配控制台；全局分配器是 mimalloc，Windows 用 VC-LTL 链到系统 CRT |
| `workspace` | 窗口实体：驱动轮询、`Effect` 执行（气泡、滚动、主题、退出）和流式分帧。每 64ms 一帧，每帧最多 80 字符 / 16 条增量；同一帧已有增量时，`ChatDone`/`ChatFailed`/`AssistantStep` 留到下一帧；工具结果与同一帧里先到的开始事件分开 |
| `workspace/projects` | 应用内目录浏览器、系统文件对话框、拖放，以及 `@`、技能、目录和会话切换的入口 |
| `workspace/conversation` | 消息撤回，以及会话、目录、服务商、MCP 共用的两次点击删除确认（3 秒） |
| `workspace/history` | 跟随底部、主题切换时保持滚动位置、靠近顶部时补更早一页 |
| `workspace/menus`、`workspace/model_menu` | 作曲栏选择器的键盘导航，以及模型、服务商、思考强度的选择 |
| `workspace/palette` | 命令面板的开关与执行 |
| `workspace/settings_editor` | 设置表单实体与保存。密钥框保存后清空，已存的钥匙不会回填 |
| `workspace/updates_data` | 自更新、导入导出、MCP 探测、`ask_user` 输入框、Esc 分层关闭 |
| `view_model`（`mycode-frontend`） | `WorkspaceState` 与 `reduce`；子模块按对话、项目、模型、设置、用量拆分 |
| `ui` | 按状态出元素。详情面板只在对话页显示；钉住时无论窗口多宽都停靠成右栏，否则是覆盖对话的浮层 |
| `ui/sidebar` | 操作条、目录、全部会话，以及项目菜单 |
| `ui/project_picker` | 应用内目录浏览器；首屏是盘符 / 文件系统根，每个目录最多列 400 项 |
| `ui/model_picker` | 两步模型选择器，作曲栏、默认模型和每个子代理角色共用 |
| `ui/chat` | 欢迎页、转录、作曲栏、`@` / `/` 菜单、模型与思考菜单、提问卡 |
| `ui/context` | 详情面板、全部改动抽屉、diff 面板和子代理小窗 |
| `ui/settings` | 设置壳：五组导航、九个页面，以及模型库、OAuth、服务商详情等二级页 |
| `driver/git`（`mycode-frontend`） | 打开目录的文件事件监视，合并后在后台线程读 `git status`，以及打开的 diff。桌面版启动时调用 `watch_git` 开启；没有改动视图的前端不开 |
| `git_status`（`mycode-frontend`） | 只读执行 `git status --porcelain=v1 -z -b --untracked-files=all` 和 `git diff HEAD`；带 `--no-optional-locks`、`--no-pager`、`--literal-pathspecs`。最多保留 80 个改动文件，diff 截断在 12,000 字节，改名/复制行打开新路径的 diff |
| `i18n`（`mycode-frontend`） | `auto` 用系统 UI 语言（Windows / macOS），其它平台回退到 `LC_ALL` / `LC_MESSAGES` / `LANG`；也可固定 `en` 或 `zh` |

终端版 `mycode-cli` 的代码在 `app.rs` 和 `app/` 下：`app.rs` 管驱动循环、终端保护和共享状态，`app/input.rs` 管按键、粘贴与三种发送，`app/settings.rs` 管设置页游标和选择器，`app/settings_rows.rs` 生成设置行，`app/ui.rs` 负责每帧绘制，`app/render.rs` 构造转录行；`reply.rs` 给围栏代码着色，`main.rs` 处理参数、更新和自安装。

## 窗口

默认 1760×1040，居中放在主屏可用区；可用区减去 64px 余量后再取请求尺寸，屏幕不够时先缩小，最小 960×560。`ui.json` 有 `windowSize` 就按它恢复；拖动结束后等 400ms 写回，最大化记录还原尺寸，全屏不写。窗口使用系统模糊（macOS 视觉效果 / Windows DWM），并去掉 Windows 11 的无边框描边。

外观只有 `dark` / `light`，其它值会让 `settings.json` 备份后重置。色板和字体族选择已移除；旧 `palette`、`fontFamily` 是未知字段，同样触发重置（见 [config.md](config.md)）。界面字体固定为操作系统 UI 字体，字重不用 500：界面强调用 600，欢迎页字标用 700，Markdown 粗体按自身渲染。字号来自 `appearance.fontSize`：`s` / `m` / `l` / `xl` = 12 / 14 / 16 / 18px；改完立即上屏并保存。标题栏、侧栏和详情是半透明毛玻璃，对话与设置页面接近实色。思考菜单和模型菜单不透明，分别贴 Thinking 按钮右缘和模型按钮左缘，在输入卡片上方展开；内容超高时菜单内部滚动。对话 Markdown 用 `TextView`，围栏代码块由内置词法高亮上色（无 tree-sitter 语法解析）。

## 侧栏

自上而下：操作条、目录、会话、底部设置与版本号。

- 有打开的目录时才显示「新建任务」；搜索框始终在，只按已加载的会话标题做不区分大小写的匹配，不读日志。
- 「添加目录」打开项目菜单：「浏览…」进应用内目录浏览器；下面是最近项目，已加入的置灰。最多同时挂 8 个目录；也可以把目录拖进窗口。
- 每个目录行悬停出现移除按钮。目录下还有会话时，第一次点变成红色「删除会话？」，3 秒内再点才删除目录及其会话；空目录点一次就移除。
- 会话列表列出全部会话，按今天 / 昨天 / 最近 7 天 / 更早 / 未知时间分组，显示相对时间。不属于当前目录的会话在标题下显示目录名。删除会话同样是两次点击。
- 坏会话占一行，只能删，不能打开。
- 点目录会打开它最新的会话；没有就新建一个绑定该目录的会话。不会把当前会话改绑到别的目录。

## 对话

- 作曲栏占位：空闲时「向代理提问 / Ask the agent」，运行中「回车排队 · Ctrl+Enter 打断发送 · Ctrl+G 引导」（macOS 上按 Cmd+Enter / Cmd+G）。
- 回合运行中按 Enter 把草稿排到本轮之后，输入框清空，排队的消息显示在输入框上方；Ctrl+Enter（macOS 为 Cmd+Enter）停止当前回合并立刻发送；回合正在为自动压缩生成摘要时（状态行显示「正在压缩上下文」），等摘要结束再停，免得白白丢掉摘要、下次发送又从头压缩。Ctrl+G（macOS 为 Cmd+G）引导：不停止回合，草稿在模型下一步之前作为用户消息交给它，读到之前显示在输入框上方的「引导中」条里；回合在那之前结束的话，退回队列。停止按钮结束整个回合和所有子代理。停止后队列保持暂停：点「发送」放行，或撤回后编辑再发。队列最多 8 条，可单条撤回修改、移除或立即发送。
- `+` 添加 `@` 文件引用；输入 `@` 搜项目文件，输入 `/` 列出内置命令和已启用技能；继续输入按名称筛出已启用的 MCP 服务器及其工具。
- 运行中的子代理以转录里的 `agent` 行出现，可单独取消；详情面板有对应卡片，点卡片或行会打开小窗，显示目标、任务、路径、当前步骤和日志。
- 打开长会话时只加载最近 40 条事件；滚到离顶部 64px 内自动补更早一页，或点「更早的消息」。补页时视口停在原内容上；在底部时继续跟随，离底 48px 内算底部。离开底部后显示跳到底部按钮。
- 思考与正文分开。每条记录可单独展开；点正在生成的思考改的是默认状态，写入 `ui.json` 的 `thinkingCollapsed`（默认展开），之后的新回复沿用，已记录的各条保持原样。收起时标题显示最新一行的末尾（最多 42 字符），正文不跟着折叠。
- 作曲栏右侧的上下文芯片：窗口已知时显示 `已用 / 窗口` 和剩余额度圆环；悬停给出最近请求命中率、缓存量和本轮 / 上一轮合计。窗口未知但报过缓存读取时，芯片只保留悬停提示；都拿不到时隐藏。
- 连续工具调用折叠成一行；展开后显示结果。长输出在列内换行，并在 2,000 字符处截断。
- 用户消息悬停可「撤回」：回退到该消息之前，并把原文放回输入框；不改工作区文件。
- 手动 `/compact` 或自动压缩写出的摘要是一张「摘要 / SUMMARY」卡片，默认只显示标题行「较早的上下文已压缩」，点开看全文。回合中途到达的摘要等回复提交后再放在最后。
- `ask_user` 的问题在作曲栏上方逐题显示，可选选项或自由文本；必答题未答不能下一步，Esc 关闭（工具收到可捕获错误，不取消回合）。

## 详情面板

标题栏右侧按钮开关；设置页不显示。默认关闭，打开和钉住状态写入 `ui.json`。点图钉：浮层变常驻右栏（316px），再点回浮层（320px）；任意宽度都能钉，不按窗口宽度切换。浮层有遮罩，点遮罩或 Esc 关闭；常驻列是界面的一部分，Esc 不关它。

自上而下：

- **子代理**：角色、任务、当前步骤、耗时和单独取消；超过并发上限排队的 artisan 会警告。点一行打开小窗。
- **改动**：分支和改动文件。预览前 6 个；「查看全部」打开全高抽屉，点文件打开 diff 面板。超过 80 个时数字带 `+`，抽屉末尾写「还有更多改动未列出」。
- **模型与用量**：名称、服务商、思考强度和上下文条；「本轮合计 / 上一轮合计」列出请求次数、累计入 / 出和本轮缓存命中。上下文条是最近一次提示的大小，合计是这一轮每次请求（每个工具回合一次）之和，所以会远大于上下文窗口。缓存命中按 OpenAI 口径计算；缓存读取大于输入时按 Anthropic 口径用输入加缓存作分母。

用量只属于当前进程里的当前会话：重开会话只从账本恢复最近一次提示的大小和缓存读取，本轮 / 上一轮合计和缓存告警不恢复。

## 标题栏与命令面板

标题栏高 40px，由客户端绘制。Windows 隐藏系统标题栏，左侧是图标、MYCode 和当前目录（设置页显示「设置」），右侧是详情开关（仅对话页）、有更新时的状态点，以及最小化 / 最大化（还原）/ 关闭。macOS 保留左上角原生红绿灯，右侧没有窗口按钮。空白处双击缩放。

`Cmd-K`（macOS）或 `Ctrl-K`（Windows）在任何页面打开命令面板，再按一次关闭。列表分四组：

- 会话：新建任务，以及所有可打开的会话。
- 模型：当前已启用服务商里未隐藏的模型，最近使用的排在前面。
- 命令：内置 `/new`、`/compact`、`/settings`，已启用技能，已启用的 MCP 服务器及其工具。
- 设置：九个设置页。

`↑` `↓` 移动，Enter 执行，Esc 关闭。选会话或大多数斜杠命令回到对话；`/settings` 和设置行打开设置；选模型只改当前选择，不切页。搜索不区分大小写，中英文关键词都能匹配。

## 欢迎页与设置

欢迎页在没有消息、也没有正在运行的回合时出现，只有「打开目录」和最近目录（最多 6 个，可删）；「新建任务」在侧栏，不在欢迎页。

设置顶栏的「返回工作台」离开设置，右侧搜索框按页面名称、说明和角色名过滤左侧导航。模型库、服务商详情、MCP 和网页等二级页用自己的返回，回到上一级而不是工作台。Esc 一次退一层。进入设置、回到工作台、切换分区或二级页时，内容做一次 140ms 的淡入；系统开启减少动态效果时直接显示。

- **通用**：主题、字号、语言（`auto` / `en` / `zh`）、思考记录开关、代理模式和连通测试。没有字体族或解释器选项。
- **快捷键**：在导航「通用」下方单独一页。按「撰写与发送」和「界面与导航」两张卡片列出，每行左边是动作和说明，右边把按键画成键帽。列表与 CLI 设置页共用 `mycode_frontend::shortcuts`。
- **模型**：默认模型（最近 3 个置顶，其余先选服务商再搜索）和默认思考强度。服务商卡片有启停、连接状态和两次点击删除；下方三个添加按钮：「从模型库添加」「OAuth 登录」「添加自定义端点」。模型库来自 models.dev 并注入内置 OpenDesign 行，跳过 device-code 服务商；每行「添加」打开勾选模型、粘贴 API key 的表单。OAuth 页是 GitHub Copilot 和 OpenAI Codex 两张设备码卡片，验证码显示在对应卡片上。再次添加 OpenDesign 会替换它的模型列表，端点和覆盖保持不变，不会生成 `opendesign-2`。服务商详情可改端点、用锁按钮更换密钥、逐个显示或隐藏模型；旧密钥不会回填到密钥框或端点框。
- **子代理**：Scout、Artisan 是两张主卡片，后面是主目录 `agents/` 或项目 `.mycode/agents/` 发现的其他角色。每张卡可启用、选模型和思考强度。每个父回合最多 8 个并发，不设超时；取消回合、单独取消、停止或删除对话时结束。
- **技能**：每个技能一行开关。关掉后仍留在列表里（变淡、隐藏「使用」），但不出现在 `/` 菜单、命令面板和代理的技能列表里，改动立即保存。
- **MCP**：服务器启停（启用前先探测）、从目录添加、导入 JSON、添加自定义服务器。
- **网页**：Querit、AnySearch、Exa 三个后端，最多启用一个；启用前做一次真实搜索探测；密钥可来自环境变量或凭据库。
- **数据**：导出 / 导入设置、界面状态和 API key，明文 JSON，不含对话。导入会覆盖本机配置；文件改动 MCP 命令时需要二次确认。
- **关于**：版本、自动更新开关、手动检查、服务商目录日期和刷新。

## 提示与更新

提示是右上角气泡，位于标题栏和设置 / 详情标题行下方，详情打开时避开右栏。Info 5 秒、Warning 10 秒后消失，Error 保留到手动关闭；相同内容的同类气泡不重复堆叠。

标题栏的更新点显示可用、下载中、待安装，点它打开更新对话框。检查到新版本后自动下载；校验完成弹出对话框并提示已就绪，点「重启并安装」立即重启，直接退出应用也会在下次启动前完成安装。自动检查在首帧渲染后跑一次，之后每 24 小时一次，两者都只在自动更新开启时执行；已是最新不提示，失败弹气泡。手动检查、目录刷新成功或失败也都只弹气泡；下载失败弹气泡并打开更新对话框。设置页不重复写状态行。

启动时如果 `settings.json`、`ui.json`、`secrets.json` 或模型目录缓存被重置，会汇总提示一次，并说明原文件留在旁边。

## 驱动与核心

核心发事件时唤醒界面任务；接收端挂起，醒来后把通道里的事件折进状态。流式文字按 64ms 一帧分片折入，每帧最多 80 字符 / 16 条增量；同一帧已有增量时，`ChatDone`/`ChatFailed`/`AssistantStep` 和工具结果留到下一帧，避免快回合只画出最终消息。流式回复缓冲上限为 256K 字符。用户消息已在排队时，界面不再分帧，直接排空事件。

打开的目录由驱动（`mycode-frontend` 的 `driver/git`）用系统文件事件监视（`notify` 的默认后端：macOS 为 FSEvents，Windows 为 `ReadDirectoryChangesW`）。`.git` 下的 `objects`、`logs`、`hooks`、`info`、`worktrees` 和 `*.lock` 不触发刷新。变化合并 300ms 后在工作线程读一次 `git status`；切换目录会丢掉旧目录还在跑的读取。工作区内容变了但 porcelain 状态不变时（例如仍是 `M`），已打开的 diff 也会跟着刷新。

`SendMessage` 和 `RecallMessage` 带上界面看到的账本头。核心拒绝过期头时，界面保持原对话并提示，不本地假装已经撤回。`RecallMessage` 只截断对话；编辑会把原文填回输入框。工作区里的文件不会被恢复或删除。

## 不放在这里的东西

不拼 HTTP，不解析会话日志，不保存密钥。设置页提交完整的 `AppSettings` 加读到的 revision；钥匙单独走 `SaveProviderKey`。
