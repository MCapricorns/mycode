# mycode-desktop

唯一的产品前端，GPUI。这个 crate 负责画，以及把点击变成 `DesktopAction`。会话、提供商、工具、路径和密钥的读写都在 `mycode-app`。

```text
GPUI 元素
    │ 点击、输入
    ▼
DesktopAction → reduce（纯函数，无 IO）
    │ 需要核心时
    ▼
BridgeCommand → CoreBridge
    │ BridgeEvent / BridgeReply
    ▼
再 reduce 一次，元素按新状态重画
```

视图模型和 GPUI 分开，是为了产品行为不依赖一块 GPU。CI 不打开窗口：拉取请求上的 `ci.yml` 只在四个原生 runner 上编译并打包发布版桌面二进制（Windows x64、Windows ARM64、macOS Apple Silicon、Linux x86_64），没有 fmt / clippy 任务。macOS 构建另外把二进制装进 `MYCode.app` 并产出 dmg 安装镜像（`scripts/make_dmg.sh`）。推到 main 时 `release.yml` 编译同样四个目标，再打标签并发布 GitHub Release。

## 模块

| 模块 | 干什么 |
| --- | --- |
| `main` | 若参数是 `--mycode-apply-update`，先替换安装文件并退出，不开窗口。否则清掉过期的更新暂存目录，解析家目录，打开窗口。发布构建在 Windows 上不分配控制台 |
| `workspace` | 窗口实体：桥、标题栏、侧栏、对话、详情面板、设置页 |
| `workspace/bridge` | 把动作译成命令，把事件译成动作，驱动一次回合 |
| `workspace/projects` | 工作区、文件夹、会话的创建、切换和删除，`@` / 技能、撤回，项目信任 |
| `workspace/git` | 文件事件监视，合并后在工作线程读 `git status` |
| `workspace/stream_frame` | 每帧（约 64ms）最多折入 80 字符 / 16 条流式增量 |
| `workspace/settings_editor` | 设置表单的保存。密钥框在保存后丢掉，不把已存的钥匙填回来 |
| `workspace/updates_data` | 自更新、导入导出、MCP 探测、`ask_user` 应答、Esc 关闭浮层 |
| `view_model` | `WorkspaceState` 和 `reduce`。子模块按对话、项目、模型、设置、用量拆开 |
| `ui` | 按状态出元素。详情面板默认关闭；窗口宽度 ≥1280 时可以钉在对话旁，否则作为浮层盖在对话上 |
| `ui/sidebar` | 工作区切换器、操作条、目录、该工作区的会话，以及项目菜单 |
| `ui/project_picker` | 应用内目录浏览器。首屏是盘符 / 文件系统根列表，每个目录最多列 400 项 |
| `ui/model_picker` | 两步模型选择器，作曲栏、默认模型和每个子代理角色共用 |
| `ui/chat` | 欢迎页、转录、作曲栏、`@` / `/` 与模型菜单、提问卡 |
| `ui/context` | 详情面板：运行中的子代理、git 改动、模型与用量；全部改动抽屉和 diff 面板 |
| `ui/settings` | 设置壳：顶栏返回工作台、五组导航（通用 / 外观、模型与服务商、子代理、工具 / MCP / 网页、数据与更新）。页面是 General、Models、Agents、Skills、Shell、MCP、Web、Data、About。Shell 在工具组里 |
| `git_status` | 只读 `git status --porcelain=v1`（带 `--no-optional-locks`，不抢 `index.lock`）和 `git diff HEAD`。最多保留 80 个改动文件，改名行打开新路径的 diff |
| `i18n` | `auto` 跟系统语言，否则用设置里的 `en` / `zh` |

视觉是 Desk：窗口使用系统模糊（macOS 视觉效果、Windows DWM、Wayland 上的 KDE 模糊）。标题栏、侧栏、详情面板和菜单是半透明毛玻璃；对话和设置的阅读区更接近实色，保证文字对比。页面是接近实色的深色底，只带一点色板的渐变。色板来自设置，默认石板灰，另外还有海洋、森林、暮色、余烬和极光。通用页把这六个色板排成一行固定宽度的色块（卡片太窄时换行），选中是一圈细环。界面字体是 `appearance.fontFamily`：缺省、空字符串或 `system` 用操作系统界面字体，另外可以选本机能够加载的 Inter、Segoe UI、PingFang、Noto Sans。字号是 `appearance.fontSize`。这三项改完立刻上屏，并写入 `settings.json`，下次启动再读回来。界面只有深色；设置里不是 `dark` 的主题或已删除的旧色板会让整份 `settings.json` 备份后重置（见 config.md）。对话 Markdown 走 gpui-kit 的 `TextView`，围栏代码块用 kit 自带的 Tree-sitter 语法高亮（`tree-sitter-languages`），不另引一套 grammar。

## 窗口里有什么

- **侧栏。** 自上而下是四块：工作区切换器（新建、重命名、删除）、操作条（有文件夹时才有「新建任务」，下面是会话搜索）、目录（标题行右侧是「添加目录」，目录行单独成组）、会话（这一工作区的会话列表，和目录分开滚动）。「添加目录」打开项目菜单：「浏览…」进应用内目录浏览器；打开了文件夹时有「信任项目 MCP」/「不再信任项目 MCP」，切换当前文件夹是否可以贡献 `.mycode/mcp.json`（写进 `ui.json`；路径比较与信任列表、MCP 加载共用，去掉末尾斜杠，Windows 上再折叠大小写与斜杠方向）；下面是最近项目，已在工作区里的置灰。一个工作区挂多个文件夹；会话显式属于一个工作区。当前文件夹是相对路径的工作目录，其它文件夹用绝对路径。首次升级会把原来的文件夹列表收成一个工作区，名字随界面语言，中文是「默认」。搜索只在已经列出的标题里做不区分大小写的匹配，不再读日志。
- **对话。** 作曲栏占位是「向代理提问 / Ask the agent」；回合进行中改为追加引导。打开长会话时只画最近一窗事件；往上滚或点「更早的消息」再按偏移取更早的一页，视口停在原来的内容上。正在底部看流式回复时，补历史不会把画面拽离底部。作曲栏只显示当前模型的名称。点开后先选服务商，再在该服务商里搜索并滚动模型；星标和最近使用钉在列表顶部。思考强度仍是旁边的短列表，只列 models.dev 公布的档位。模型和思考强度按会话钉在 `ui.json`，切换会话时各自恢复，不改 `settings.json` 里保存的默认强度。同一行右侧是上下文计量 `已用 / 窗口 · N 缓存`：已用是最近一次提示的大小，窗口未知时不显示比值，只有缓存读取大于 0 时才带 `· N 缓存`，两者都是 0 时整块隐藏。回合进行中发送按钮变成停止，结束整个回合和所有子代理；这时发出的文字是追加引导，不取消子代理。排队的未发送消息最多 8 条。手动 `/compact` 或自动压缩写出的摘要在转录里是一张「摘要 / SUMMARY」卡片；回合中途产生的摘要等这一回合提交后再排到最后。子代理不在转录里重复刷进度；底部状态行和详情面板里的卡片各有一处，结束后卡片消失。
- **详情面板。** 标题栏右侧的按钮打开或关闭，面板头上的图钉在宽窗口里把它钉成一栏。自上而下：运行中的子代理（点开看目标、任务、路径和当前步骤的小窗，可以取消）；改动（预览前 6 个文件，「查看全部」打开全高抽屉，点文件看 diff；超过 80 个时数字带 `+`，抽屉末尾写「还有更多改动未列出」）；模型（名称、服务商、思考强度、上下文条、输入、输出、缓存及占比、轮次，回合中另有实时入 / 出）。
- **标题栏。** 全平台由客户端绘制（CSD）。系统标题栏隐藏（macOS 的红绿灯挪到窗口外），最小化、最大化、关闭在右侧，空白处双击缩放。
- **欢迎页。** 没有打开文件夹时只有「打开目录」。打开文件夹后才出现「新建任务」。最近项目可以删。
- **设置。** 顶栏的「返回工作台」离开设置；目录、服务商详情、MCP 和网页的二级页用自己的返回，回到上一级而不是工作台。进入设置、回到工作台，以及切换分区或二级页时，内容做一次很短的淡入。系统打开减少动态效果时，这些淡入直接显示，不做透明度动画。模型先选服务商，再搜索。服务商详情里的端点可以改，校验和保存走设置文档；密钥框在已保存时显示锁，点锁是换一把新的，旧钥匙不会被填回输入框，也不会填进端点框。子代理设置里 Scout 和 Artisan 仍是两张主卡片，后面才是主目录 `agents` 或项目 `.mycode/agents` 里发现的其他角色。steward 和 sentinel 不是默认角色。并发默认仍是 4（`0` 表示这个默认值，不是零个，也不是四种角色）。Shell 在「工具 / MCP / 网页」这一组，不在通用页。MCP 的添加在二级页：目录、导入 JSON、自定义。窗口打开后直接是工作台，没有启动遮罩。

提示是右下角短暂气泡。更新在右上角：可更新、下载中、待安装。下载校验完成后弹出对话框，确认才重启安装。关于页手动检查或下载失败只弹这个气泡，状态行写「上次更新失败」，不再把整段网络错误铺成大红字。启动后的自动检查失败也弹同样的气泡；已是最新则不提示。启动时若设置、界面状态、密钥或模型目录缓存被重置，同样只提示一次，并说明原文件留在旁边。

窗口开在主屏可用区域正中。屏幕比默认的 1520×960 小，就先缩小再居中，最小约 960×560。

## 视图模型

`reduce` 是唯一改 `WorkspaceState` 的地方。模型选择、设置的 revision、更新状态机、排队的未发送消息（有条数上限）、更早一页转录的拼入，都是动作。渲染层可以克隆它需要的切片，不能自己改会话归属或用量合计。

流式回复有字符上限。用量在回放（只有模型名）和实时（provider/model）之间按同一把钥匙合并，缓存占比在重建后还在。详情面板先找精确的 provider/model 行，再找同名模型，再退到上一回合实际跑过的模型。缓存占比按 OpenAI 口径（缓存算在输入里）计算；缓存读取大于输入时按 Anthropic 口径用输入加缓存作分母。

坏会话在侧栏占一行，只能删，不能打开。

## 和核心的节拍

核心发事件时唤醒界面任务：接收端挂起，醒来后把排在通道里的事件折进状态。流式文字按约 64ms 一帧分片折入，回合结束事件留到下一帧，避免快回合只画出最终消息。界面和核心都不阻塞对方。

打开的文件夹由系统文件事件监视（`notify` 的默认后端：macOS 为 FSEvents，Windows 为 `ReadDirectoryChangesW`）。`.git` 里对象库、日志、hooks 和 `*.lock` 的变化不触发刷新。变化先合并约 300ms，再在工作线程读一次 `git status`；切换文件夹会丢掉旧文件夹还在跑的读取。自动检查更新在启动时跑一次，进程活过大约一天后再跑一次。失败会提示；已是最新不提示。

`SendMessage` 和 `RecallMessage` 带上界面看到的账本头。核心拒绝过期头时，界面保持原对话并提示，不本地假装已经撤回。`RecallMessage` 只截断对话；编辑会把原文填回输入框。工作区里的文件不会被恢复或删除。

## 不放在这里的东西

不拼 HTTP，不解析会话日志，不保存密钥。设置页提交的是完整 `AppSettings` 加上读到的 revision；钥匙单独走 `SaveProviderKey`。
